01 / THE CABINET

Only while you wait.

No permanent widget and no interruption to the composer. Interlude watches structural page signals, then puts a compact cabinet below the response indicator when it can find a safe anchor.

FOCUS GATED

Game keys stay out of the composer. Press Alt+G to focus, Escape to return.

LOCAL FIRST

Scores and play-time statistics stay in local browser storage. No extension analytics.

YOUR RULES

Adjust games, sound and placement. Optional Focus Guard budgets are off by default.

03 / INSTALL

Load the cabinet.

Interlude is distributed as an unpacked Chrome extension, not a browser web app.

  1. Download the ZIP and checksum from the GitHub release, then verify and extract it.
  2. Open chrome://extensions, enable Developer mode, and choose Load unpacked. Select the extracted folder containing manifest.json.
  3. Reload an existing supported site tab, send a prompt and give it a moment. Click the cabinet or press Alt+G to play.

04 / PRIVACY

Your conversation stays yours.

Adapters inspect page structure and timing, not chat text. The release checker is on by default and the signed selector checker is opt-in; both make credential-free requests. Standard network metadata is still visible to servers. Read the privacy details and signing notes.
