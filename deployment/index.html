GET STARTED / CHROME

Load the cabinet.

  1. Download the ZIP and checksum from the GitHub release, then verify and extract it.
  2. Open chrome://extensions, turn on Developer mode and select Load unpacked. Choose the extracted folder containing manifest.json.
  3. Reload a supported chat tab. Send a prompt, then click the cabinet or press Alt+G to play.

03 / PRIVACY

Your conversation stays yours.

The web arcade runs in this page and does not connect to your chats. The extension inspects page structure and timing, not chat text. Its optional release and selector checks use credential-free requests. Read the privacy details and signing notes.

STAGING

The optional selector feed uses a staging signing key. It is off by default; rotate the key offline before relying on remote selectors in production.
