# Security policy

Please report security vulnerabilities privately using GitHub's private security
advisory feature if available. If it is not enabled, contact a maintainer
privately rather than opening a public issue. Do not send real conversation
contents or private keys. Maintainers should acknowledge reports promptly and
coordinate a fix before disclosure.

For selector signing, key rotation, the staging-key warning, deployment and
network trust boundaries, see [docs/SECURITY.md](docs/SECURITY.md).
